请帮我构建一个可运行的移动端 Web App Demo，名字叫 Verdant。
这是一个植物成长记录工具。  A Plant memory journal。它不是效率工具，也不是提醒软件，而是一个围绕“植物成长记忆”的记录体验。
核心价值：帮助用户通过记录植物日常变化（浇水、长新叶、换盆、拍照），看到植物随时间成长的过程，便捷清晰掌握植物的生长状态变化，并获得一种温柔的陪伴感。
产品关键词：
- Plant Memory Journal
- Growth over time
- Quiet, warm, reflective
- Gentle interaction
- Visual storytelling

---

# 技术要求
请构建：
- Next.js
- TailwindCSS
- Mobile-first
- LocalStorage 存储（不要数据库）
- 可直接部署到 Vercel
- 使用 mock 图片和 mock 数据初始化

不要实现：
- 登录注册
- 云同步
- 分享
- 社交
- 后端 API
- AI识别
- 推送通知
这是纯前端 demo。

# 记录页
极简快速记录体验
把已有植物列表做成类似图书馆标签卡片形式，点击标签后，进行记录操作

字段：
选择植物
Action：
- 💧 Water
- 🌱 Fertilize
- 🪴 Repot
- ✂️ Prune

State：

- 🌿 New leaf
- 🌸 Blooming
- ⚠️ Sick
- 💚 Looking beautiful
（Action 和 State区域的按钮/标签，风格统一的基础上有所区别）
Photo upload
Optional note

Save

保存后写入时间线
交互要非常轻量，像记录日记，不像填表。
所有上传的图片在保证手机端清晰度的情况下，限定大小以及进行压缩。
